Acerca de esta aplicación

Características generales

Modelo 3D interactivo del Sistema Solar construido con Three.js (HTML + CSS + JavaScript). Incluye posiciones keplerianas aproximadas, tiempo real o acelerado, seguimiento de cámara, órbitas, lunas principales, paralaje estelar y nebulosas procedurales.

Estructura de archivos:

  • index.html — página principal y UI
  • css/style.css — estilos del panel y del modal
  • js/main.js — escena Three.js, órbitas, shaders y controles
  • textures/ — mapas de planetas, anillos, Sol y memoria del eclipse
  • efemerides.json — momentos de interés (eclipses, etc.)
  • README.md — documentación y despliegue en GitHub Pages

Puedes alternar entre texturas procedurales (shaders) y texturas de imagen de la carpeta textures/ con el interruptor del panel.
